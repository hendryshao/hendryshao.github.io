CMAI Unified Portal

A multi-tenant property-management web app serving three distinct role surfaces — tenant, property manager, and owner — from a single Next.js 14 codebase. Tenants submit and track maintenance requests; managers dispatch vendors and work a live queue; owners see portfolio-level reporting. Fully bilingual (EN/FR), with an AI-assisted message inbox on both the tenant and manager side.

The hard part Three roles reading the same tables meant access control couldn't live in the UI. Every surface is gated by Postgres row-level security with resolver functions, so a route guard failing is an inconvenience rather than a data leak — the middleware is UX, the database is the boundary.
